# Mockup

Interactive prototype: `mockup/index.html`, published as a private artifact: https://claude.ai/artifact/WfGvVxMvLCzaXXb3EvJFRo (feedback box per screen).

Screens: Library, Now playing, Playlists, Playlist detail, Smart playlist builder, Download, Tag editor, Wi-Fi transfer, Settings, Android Auto and lock screen.

Design direction: dark-first, accent colour taken from the current album art, vinyl record behind the cover, waveform seek bar, quick-mix tiles for smart playlists. No "offline" badge (everything is offline).
